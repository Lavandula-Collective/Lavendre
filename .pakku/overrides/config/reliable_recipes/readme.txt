Lavendre modifies crafting recipes and recipe types to override, remove, or replace their inputs, outputs, or workstations to support the pack's intended gameplay.

You may modify these files to suit your own preferences or personal server configuration. Do not modify them if you want to retain Lavendre's intended gameplay.

/cooking ingredients
- bacon.json - Replaces the bacon input and output from LD:FC with the equivalent FD items.
- chicken_cuts.json - Replaces the chicken parts input and output from LD:FC with the equivalent FD items.
- dough.json - Replaces the dough input and output from LD:FC with FD wheat dough. Removes the FD and UD alternative wheat dough recipes, making the LD:FC crafting bowl method the standard.
- minced_beef.json - Replaces the minced beef input and output from LD:FC with the equivalent FD items.

/items
- fc_pot_cooking.json - Removes the LD:FC Cooking Pot recipe type from all recipes that use it, effectively removing the workstation from those recipes.
- hide.json - Adds CraftTweaker defined #lavendre:leather_alt item tag to leather alternatives.
- rolling_pins.json - Removes multiple tags from UD rolling pins and replaces selected crafting inputs for LD:B and UD rolling pins.
- ropes.json - Replaces the rope input and output from LD:FC with the equivalent FD items. Removes the Comforts alternative rope recipe and the LD:FC rope recipe.

/plants
- coffee.json - Replaces the coffee bean input and output from LD:HB with the equivalent RD items. Replaces the manual coffee bean input for the LD:HB milk coffee drink with the LD:HB coffee drink, adopting RD's manual crafting/conversion method. Removes the default LD:HB milk coffee drink recipe in favor of a data-driven recipe using LC:DP.
- onion.json - Replaces the onion input and output from LD:FC with the equivalent FD items.
- tomato.json - Replaces the tomato input and output from LD:FC with the equivalent FD items.
